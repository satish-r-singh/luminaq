Thesis the brief

Two claims, taken literally

The build brief in the repository describes the target as “an editorial art book moving through a live 3D world, not a conventional product landing page.” Everything else on the page follows from taking that sentence at face value.

The page is a camera. Scrolling does not animate elements; it advances a camera along a continuous path through one world. There are no scene changes. The six sections are six composed shots of the same sanctuary, and the transitions between them are camera moves.

The frame is one photographic image. Vignette, grain, bloom, chromatic aberration and the cursor are applied above everything — including the navigation. They are lens effects, not UI chrome. That single decision is what makes HTML type sitting on top of WebGL read as one photograph instead of an overlay.

Avoid frameworks, build tooling, analytics, trackers, remote fonts, placeholder imagery, generic glassmorphism, excessive glow, and decorative motion without narrative purpose.PROMPT.md — the exclusion list

That last clause governs the whole piece. Every animation documented below is diegetic: something happening in the world, or something the camera is doing — never an effect applied to a box.

The near plane outranks the UI

Grass, a stone lantern and a pine branch pass in front of the navigation bar. That is only sensible if you accept the thesis: these cut-outs are the closest thing to the lens, so of course they occlude everything. Because .page is a stacking context at z-index 10, nothing inside a section can ever rise past the nav — so the active foreground stage is physically re-parented out of its section into a container that can.

Type carries its own scrim

Every type token in the sheet ships with a near-black shadow at high blur. That is not styling; it is legibility insurance for text set over an unpredictable, moving background.

/* not a drop shadow — a per-token scrim */
.body-lg  { text-shadow: 0 1px 20px rgba(3,6,8,.88); }
.display  { text-shadow: 0 2px 34px rgba(3,6,8,.72); }
.hero-sub { text-shadow: 0 1px 26px rgba(3,6,8,.95); }

The author later removed a large scrim from the hero and recorded the measurement in a comment: headline contrast fell 15.98:1 → 15.47:1, standfirst 7.94:1 → 7.75:1. The scrim was “darkening the approach, the gate and the lower steps to buy half a point of contrast nobody was short of.” Scrims are paid for in scene visibility, and the payment gets justified with numbers.

The camera has mass

Six waypoints — eye, look-at target and focal length — feed two Catmull-Rom splines. Scroll maps to a float in section-index space, and the camera reads a damped copy of it, never the raw value.

RIG.smooth = damp(RIG.smooth, RIG.prog, 5.2, dt);

// frame-rate independent: identical at 60 and 120 Hz
damp = (cur, to, rate, dt) => lerp(cur, to, 1 - Math.exp(-rate * dt));

This one line is what separates a dolly from a scrubber. Drag the input below quickly and watch the two markers diverge.

Responsive means recomposing the shot

Every waypoint was framed for a wide viewport. On a tall one, rather than let the sides fall away, the rig steps back along its own view axis and widens the lens.

// a cinematographer's answer to a responsive problem
nf = clamp((1.62 - vpW()/vpH()) / 1.05, 0, 1);
p.addScaledVector(viewAxis, nf * 8.2);  p.y += nf * 1.1;
fov *= (1 + nf * .40);

Generalises past 3D: when a composition breaks at a new aspect ratio, adjust the framing, not the contents.

A reading pace, not a duration

Three nested stagger scales, all one-shot. Headings are split into words at runtime, each word masked and delayed by its index. The interval is tuned to how fast a person reads, which is why it survives being watched twice.

D 02 Word stagger change the interval, then replay

transform .82s · opacity .5s · cubic-bezier(.16,1,.3,1) 0 ms reads as a block. 200 ms reads as a stunt. 72 ms reads as reading.

Opacity finishes before transform does, so the word is fully visible while still travelling — that reads as arrival rather than fade-in.

It fires once, and it stays accessible

io.unobserve(e.target);   // first intersection only

Re-animating on scroll-back is the clearest tell of decorative motion. Content that re-introduces itself every time you pass it is a gimmick; content that arrives once has been delivered. Meanwhile the original phrase is written back as aria-label, every generated word span is aria-hidden, and under reduced motion the splitter returns before splitting anything — the heading is never fragmented at all.

Three easings, one workhorse

--ease:     cubic-bezier(.22,.61,.36,1);   /* general   */
--ease-out: cubic-bezier(.16,1,.3,1);      /* the one   */
--ease-io:  cubic-bezier(.65,0,.35,1);     /* ambient   */

--ease-out covers most of its distance in the first third of the duration. That is what lets durations as long as 1.05 s still feel immediate: the element is nearly where it is going almost at once, then settles.

Nothing toggles; things hand off

Each chapter owns a set of transparent cut-outs. When a chapter takes the viewport its set is re-parented into a fixed container above the nav and its pieces rise 90 ms apart. The outgoing set is not hidden — it is retired: it fades, drifts, and blurs, then parks back home 820 ms later.

Hover changes the world, not the button

The strongest interaction idea on the page. Hovering a chapter chip or a curriculum row does not merely style the row — it sets a focus target that damps toward 1 and then raises the hall's interior light by 30%, swells the moon's halo, and lifts every lantern in the valley by 55%. The target is in the DOM; the response is in the scene. The page warms when you pay attention to it.

Below that sits a second, cheaper principle that any page can use: almost nothing here merely changes colour. Hovers are directional.

Windows punched through the page

The three garden cards are not images. Each gets its own perspective camera aimed at a different corner of the sanctuary, rendered to its own buffer and blitted into the composite at the element's bounding rect. Hovering pushes that camera 0.55 units along its view axis — the view leans in, not the card. Two economies keep it cheap: each card re-renders only when moving or when its slot in a 24-frame rota comes up, and culling is done on effective opacity walked up the whole parent chain, not just on the rect, because the canvas knows nothing about the DOM stacked over it.

The plates are cloth

Each card's still is mapped onto a 96×96 GPU cloth simulation stepped at a fixed 120 Hz, driven by procedural wind, with the pointer imprinting a Gaussian dent through a critically-damped spring follower. The card's hairline border is drawn in the fragment shader, off the same distance field that cuts the fabric out — so it rides the folds. As the comment puts it: “A CSS outline can only ever trace the flat rectangle the cloth has left.” It halts when the card leaves the viewport, and again once the wind dies and the fabric settles.

The cursor is two things

A CSS ring that lerps toward the pointer at .18 per frame — so it lags, which reads as weight — and a WebGL particle trail parented to the camera rather than the world, so it stays under the hand while the rig drifts. Its emission model is the detail worth stealing outright.

What holds it together

A closed-loop performance governor

Frame time above 23 ms scales render resolution down; below 13.8 ms it climbs back in 8% steps, floor 0.55. There is an explicit sacrifice order — MSAA first, then device pixel ratio, then particle counts. Shadows are baked exactly once because nothing that casts one ever moves. Animation dt is clamped to 50 ms while the governor reads the true elapsed time: “animation never jumps… but the governor reads the truth.”

A fallback that is designed, not handled

If WebGL fails, a .no-webgl class turns the page into a deliberately composed static page: a CSS-gradient night sky with a vermilion moon, painted card frames, the 3D wordmark migrating into the DOM as a background-clipped headline, and a foot scrim the live hero does not need — because the fallback's sky is brighter. The page stays a page.

Reduced motion preserves the reading

Beyond zeroing durations: headings are never split into words, foreground stages park immediately instead of retiring, the cloth composes one frame and stops, and the camera reads raw scroll progress with no damping so scrolling is exactly 1:1. Nothing is withheld; only the motion is.

The comments are part of the method

Nearly every non-obvious rule carries a comment explaining the perceptual reason it exists or the specific bug it fixes, with measurements. Six months on, nobody has to re-derive why the backdrop-filter sits on a pseudo-element rather than the bar.

Judge the frame by its shape, not its width. What forces the word up and in is a tall frame, and a 768-wide tablet held upright is as tall as a phone — on a width test it took the desktop baseline and sat below the fold with only the top of the G showing.index.html — wordmark layout

What crosses over

Kage is an art piece where the load is the experience. LuminaQ is a conversion page measured on LCP and time-to-CTA. The philosophy transfers cleanly; the implementation mostly does not.

Take it

  • The lens layer. A fixed grain and vignette above all content — about twenty lines, and it makes a flat dark page read as photographed.
  • Word reveals at ~72 ms, one-shot. In Framer Motion: staggerChildren plus useInView({ once: true }).
  • Stop re-animating on scroll-back. A free credibility gain.
  • Directional hovers. Fills that arrive, rules that wipe, rows that indent — instead of colour changes.
  • Non-harmonic ambient loops for anything that glows: two tracks, periods that don't divide.
  • Hero exit choreography. useScroll with per-element ranges, biggest element leaving first and blurring. The single highest-impact change available.
  • Layout variants as body data attributes — a clean way to test whole compositions without forking the stylesheet.

Adapt it

  • Hover with consequence. No 3D scene needed — hovering a RedFlags row can warm a shared ambient gradient behind the whole section. The point is that a hover can have an effect larger than its own box.
  • Handoff transitions (fade + drift + blur, ~700 ms) for the quote modal and any pricing-tier swap.
  • The type-scrim discipline anywhere copy sits over imagery — Hero, Proof, TheAuditor.
  • Narrated progress. A due-diligence product could name its stages the way Kage names construction jobs — but in-product, not in front of the page.

Leave it

  • The WebGL world. 600 KB of Three.js plus 2.4 MB of plates is defensible for an art piece and indefensible for a page selling a discovery call.
  • The construction preloader. Twelve staged jobs in front of a pricing table is a bounce generator.
  • The custom cursor. Fine-pointer only by design, and it costs more in familiarity than it returns in atmosphere.
  • Copy hidden for composition. Kage visually hides its chip descriptions in one layout variant. A landing page cannot trade away copy for balance.
