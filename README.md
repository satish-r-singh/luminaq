# luminaq.ae

The Luminaq website. Plain HTML, CSS and JavaScript, bundled by Vite. No framework.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build into dist/
npm run preview    # serve the built site locally
```

Deployed by Cloudflare Pages from `main`. Build command `npm run build`, output directory `dist`.

See `.claude/CLAUDE.md` for how the site is organised and the rules for changing it.
